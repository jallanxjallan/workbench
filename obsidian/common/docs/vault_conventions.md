# Vault Conventions

## Purpose

`_common` is the reusable system layer shared across Studio vaults.

## Allowed Contents

- templates
- inspection queries
- macro documentation
- workflow conventions
- configuration notes

## Disallowed Contents

- project notes
- scratch notes
- pipeline output
- experiments
- temporary work products

## Related Vault Folders

- `contents/`: authored passages and related content notes.
- `topics/`: topic notes and research structures.
- `images/`: image metadata and supporting assets.
- `_vault_registry/`: vault identity metadata when present.

## Archive Rule

If an item is no longer part of the stable shared layer and its status is uncertain, move it to `_common/_archive/`.
