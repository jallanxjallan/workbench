# Create Passage

Purpose: create a new passage note from `_common/templates/passage_template.md`.

## Expected Behavior

1. Prompt for note title.
2. Create a markdown note in the target vault.
3. Apply the passage template.
4. Leave required metadata ready for manual completion.
