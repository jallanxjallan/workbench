# Apply Template

Purpose: apply a standard template to the active note or current selection.

## Expected Behavior

1. Read the current note context.
2. Choose the target template from `_common/templates/`.
3. Merge missing frontmatter keys without overwriting authored content.
4. Preserve the existing note body unless the macro explicitly replaces it.
