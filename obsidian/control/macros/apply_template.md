# Apply Template

Purpose: historical documentation only.

## Current Rule

- Active Obsidian macros must not rewrite existing notes.
- Template application belongs to explicit Workbench or archived legacy flows only.
- New note creation may seed content from `_control/templates/`, but existing note mutation is not part of the active subsystem.

## Notes

- This note remains as a reminder that the pre-NDJSON mutation model is retired.
